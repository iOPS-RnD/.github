# iOPS — Intelligent Operated Power System

iOPS is a research and development initiative supporting intelligent and reliable power-system operation.

Focus areas:

- operational analysis
- decision support
- semantic technologies
- AI
- the control room of tomorrow

The organisation hosts R&D projects, synthetic and open datasets, specifications, software, demonstrations and shared research resources.

iOPS is an umbrella initiative, not a project. The projects and shared research assets below belong to its ecosystem; each is hosted and governed where its link points.
